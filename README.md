# Dental Motion — Page 01 (Real 3D Tooth)

This version replaces the previous flat SVG tooth with a real WebGL/Three.js 3D tooth.

## Run
```cmd
npm install
npm run dev
```
Open http://localhost:3000

## Interaction
Scroll through the pinned hero. The tooth rotates around its real 3D Y axis, tilts, shifts in space, and the camera moves slightly with scroll progress.
